# Data

This directory has five access tiers. Only `publicly_available/` is distributed with the
repository; the other four are gitignored and must be obtained separately.

| Tier | Distributed here? | How to obtain |
|---|---|---|
| `publicly_available/` | **Yes** — CC BY 4.0, see `LICENSE` | Already present |
| `upon_request/` | No | Reasonable request to the corresponding author |
| `collaborator_only/` | No | Executed Data Use Agreement with the Principal Investigator |
| `private/` | No | Most restricted; institutional review required |
| `published_data/` | No | Third-party. Download from the original sources yourself |

Requests: **Lenore J. Launer — launerl@nia.nih.gov**

See the *Data access* section of the top-level `README.md` for the file-by-file map of which
analyses each tier gates, and `manage_project/setup_data_links.sh` for wiring up a directory you
already hold.

Individual-level AGES–Reykjavik data cannot be redistributed. The tiers exist to protect
participant privacy.
